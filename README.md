<h2 align="center"> 🎯 Problem Statement</h2>
<h3 align = "center"> <u><i>Agentic Evaluation Framework </i></u>
</h3>

<h4>
  Context
</h4>

As AI agents become more powerful, evaluating them becomes critical. When we prompt an 
agent to perform a task, how do we ensure it: 
- Follows instructions exactly? 
- Doesn’t hallucinate facts? 
- Avoids unwarranted assumptions? 
- Provides coherent and accurate responses?

Now imagine this at scale: we have 100 agents, each producing thousands of responses. 
Manual evaluation is impossible. What we need is a scoring framework that can 
automatically grade responses across multiple dimensions. This is a crucial step toward 
building trustworthy AI systems.

<h4>
  The Challenge
</h4>

To design a framework for large-scale agent evaluation that: 
- Accepts prompts, responses, and metadata for 100s of agents. 
- Scores responses across dimensions: 
  - Instruction-following 
  - Hallucination detection 
  - Assumption control 
  - Coherence & accuracy
- Outputs an interpretable performance report.
<hr>

## 🚀 Solution

This project provides a Streamlit-based evaluation framework for analyzing responses generated by multiple AI models (e.g., GPT, LLaMA, etc.).
It integrates multiple evaluation modules into a single pipeline and outputs detailed scores at both overall and per-requirement levels.

**#🔎 Key Evaluation Modules**

**1. Instruction Following Evaluator**

Extracts requirements directly from system instructions (via regex + embeddings).
Evaluates responses for:
- Context-only usage
- Tone (professional / casual)
- Formatting (bullets / paragraph)
- Security checks (e.g., disclaimers for medical/engineering advice)
- Task-specific instructions (summarization, persona, reasoning steps, etc.)

Produces:
Overall Score → ratio of requirements fulfilled vs. asked
Detailed Report → per-requirement breakdown

**2. Hallucination Detector**

Identifies when a model introduces information not supported by the provided context.
Uses semantic similarity, new entity detection, vague language markers, and readability metrics.
Trained a transformer architecture on pre built dataset of hallucinated and non hallucinated sentences, achieved comparable results to MHEM(Hughes Hallucination Evaluation Model).

**3. Assumption Detector**

Detects whether the response makes assumptions not supported by context.
Focuses on:
- Speculative words/phrases or Linguistic hedging (e.g., “might”, “possibly”, “some say”)
- Context mismatch (using embeddings)
- Readability and coherence cues
- Entity leakage (new assumptions about people, events, or facts)

Outputs:
- assumed (True/False)
- Confidence Score (0–1) → strength of assumption detection
- Explanations for flagged assumptions

**4. Accuracy Evaluator**

Measures whether the response is accurate w.r.t. the context.
- Cross-checks key claims in the response against context embeddings.
- Highlights factual mismatches (e.g., wrong dates, names, places).
- Computes semantic similarity and correctness score.

Outputs:
- Accuracy Score (0–1)
- Mismatched Segments if detected

**5. Coherence Evaluator**

Measures how logically consistent and well-structured a model’s response is.
Uses sentence embeddings + semantic similarity across sentences to detect:
- Contradictions
- Sudden topic shifts
- Incoherent or disjointed explanations

Produces:
Coherence Score (0–1) → higher = more internally consistent
Explanations for low scores (e.g., "Topic drift detected", "Contradictory claims")

**#📊 Integration with Dataset**

For each AI system column (e.g., GPT_AI, LLAMA_AI, etc.), the framework appends:
- inst_follow_MODEL → overall instruction following score
- inst_eval_MODEL → detailed instruction compliance report
- hallucination_MODEL → hallucination detection results
- assumption_MODEL → assumption detection results
- accuracy_MODEL → accuracy score

This allows side-by-side comparison of different models across multiple evaluation axes.

**#🚀 Deployment**

Implemented in Streamlit for easy interactive use.
Users can:
- Upload a dataset (.csv) with prompts, context, and model responses
- Run evaluations across all detectors
- View detailed reports in-app
- Export enriched results back to .csv for further analysis

## 📊 Evaluation Dimensions

The detailed explanation of the key dimensions used to evaluate agent responses:

### <u> Instruction-following </u>
This dimension checks whether the agent’s response aligns with the instructions provided in the prompt. It ensures that the output directly addresses the task without deviating from the requirements.

### Hallucination detection
This dimension identifies cases where the agent invents or fabricates information that is not verified or supported by facts. It helps prevent the spread of misleading or false content.

### Assumption control
This dimension ensures that the agent does not add unwarranted assumptions, biases, or extrapolations beyond what is explicitly asked in the prompt. It maintains the integrity and relevance of the response.

### Coherence & accuracy
This dimension assesses whether the response is logically structured and factually correct. A coherent answer maintains consistency throughout, and accuracy ensures that the information is valid and trustworthy.
